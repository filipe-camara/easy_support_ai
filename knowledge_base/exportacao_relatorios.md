# Procedimento de exportação de relatórios

## 1. Formatos permitidos
Os formatos disponíveis podem incluir: PDF, CSV, XLSX, JSON.

## 2. Procedimento de exportação
1. Acessar o módulo de relatórios.
2. Selecionar o relatório autorizado.
3. Aplicar os filtros necessários para limitar os dados ao mínimo indispensável.
